Tips

  • Buy where you're fitted. If you buy parts from several places, set up the bow yourself or pay a shop for technician time.
  • Online-only bundles. Merlin sells some bundles online only, so ask in store for the in-store price.
  • Used kit. Your club is the best place to start. sellmybow.com is a UK marketplace for used equipment; read Buying second-hand first.
  • Governing body. Archery GB and its Start Archery site have beginner kit guides and a club finder.
