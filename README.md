# UK Olympic Recurve Buying Guide

A static website with my opinions on buying Olympic recurve equipment in the UK at three levels (Starter, Intermediate and Advanced), plus a list of UK shops I recommend. It doesn't list prices: readers check those with the shops.

**Live site:** https://vil-bekesius.github.io/recurve-buying-guide/

## How it works

The site is plain HTML and CSS generated by a small Python script with no dependencies.

```
content/            page bodies as HTML fragments
data/products.json  every product table
style.css           site styles (light and dark mode)
build.py            combines the above into docs/
docs/               generated site, served by GitHub Pages
```

A page includes a product table by writing `{{table:<id>}}`, where `<id>` is a key under `tables` in `data/products.json`.

## Updating content

1. Edit `content/*.html` or `data/products.json`.
2. Rebuild:

   ```bash
   python3 build.py
   ```

3. Commit both your edits and the regenerated `docs/` folder, then push. GitHub Pages republishes within a minute or two.

## Preview locally

```bash
python3 build.py
python3 -m http.server -d docs 8000
```

Then open http://localhost:8000.
