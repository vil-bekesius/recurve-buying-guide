# UK Olympic Recurve Buying Guide

A static website that helps UK archers choose and buy Olympic recurve equipment at three levels (Starter, Intermediate and Advanced), with prices and links from reputable UK specialist shops.

**Live site:** https://vil-bekesius.github.io/recurve-buying-guide/

## How it works

The site is plain HTML and CSS generated by a small Python script with no dependencies.

```
content/            page bodies as HTML fragments
data/products.json  every product table: names, prices, links
style.css           site styles (light and dark mode)
build.py            combines the above into docs/
docs/               generated site, served by GitHub Pages
```

A page includes a product table by writing `{{table:<id>}}`, where `<id>` is a key under `tables` in `data/products.json`. `{{checked}}` inserts the price-check date.

## Updating prices

1. Edit `data/products.json` (and the `checked` date at the top).
2. Rebuild:

   ```bash
   python3 build.py
   ```

3. Commit both your edits and the regenerated `docs/` folder, then push. GitHub Pages republishes within a minute or two.

If you change a build's parts, update its "Total" row and the price ranges in `content/index.html` and `content/before-you-buy.html`.

## Preview locally

```bash
python3 build.py
python3 -m http.server -d docs 8000
```

Then open http://localhost:8000.
